# Product evidence

Use the authorized browser and an existing project collector or harness.

1. Preflight fixtures, schema, bootstrap and runtime. Confirm the route, resource, saved revision and controls before mutation. Wait for fonts, saved values and export state to settle.
2. Capture required initial state before mutation. Retain downloads immediately, verify their identity, and record resource, revision and audience before cleanup.
3. Inspect one real example per renderer, audience layout or export path early. Inspect required final outputs too; a representative does not prove every layout. Add links to the task record or a useful compact gallery as work finishes.
4. Separate product defects, collector failures and missing evidence. Name the unproved claim; missing evidence can leave a required gate open without proving a defect.
5. Fill gaps with targeted captures when source, inputs and state are known. Replay the full journey only when needed to establish state or causality. Preserve historical failures and verdicts; label retrospective evidence, keep timelines separate, and never backdate or weaken acceptance.
