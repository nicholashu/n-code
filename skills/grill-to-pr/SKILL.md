# Grill to PR

Read each skill when you reach its step. Find it in the current skill catalog, or in sibling directories after resolving this skill's symlink. Report missing dependencies.

1. Apply the installed interview skill, `grill-me` or `grilling`, and read its dependencies. Reuse settled answers. Wait for actual answers and the required final confirmation before implementation. Skip the interview if the user already confirmed the agreement.
2. Apply `build-brief` to record the scope, acceptance evidence and delivery boundaries. Resolve material gaps without reopening settled decisions or adding another approval step.
3. Apply `t3-orchestration` within the runtime's delegation rules. Implement, verify, repair and prepare the authorized PR. Keep routine work direct where that skill requires it.

Continue until delivery is complete or a blocker, required approval or user pause prevents it. Honor narrower requests, including stopping after the brief. Discussion of this workflow does not start a feature.

Default to a draft PR. Merge and production require explicit current-task authority. Preserve project release holds and report unverified results.
